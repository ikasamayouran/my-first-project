# 自分専用アプリ

個人利用のためのWebアプリ。データはブラウザのlocalStorageに保存され、サーバーは不要。

## 使い方

`index.html` をブラウザで開くだけで動作する。もしくは簡易サーバーで配信する場合:

```
python3 -m http.server 8000
```

## 機能

- **食べログ**: 訪問したお店を記録・検索・評価できる（実装済み）
- **旅行ルート作成**: 近日公開予定
- **競馬予想**: レース・出走馬の登録、簡易スコアによる予想順位算出、結果・収支の記録ができる（実装済み）
  - 出走馬ごとに馬番・馬名・性齢・騎手・人気・オッズ・前走着順・体重・父小系統(血統)・自己評価を入力できる
  - 人気・オッズ・前走着順・自己評価を入力すると、簡易スコアで予想順位を算出
  - レース後に着順・購入金額・払戻金額を記録すると、予想的中率や収支・回収率を自動集計
  - CSV/TSVファイルの読み込みに対応。JRA-VANのエクスポートCSV（Shift-JIS）やnetkeibaのダウンロードデータ（UTF-8）など、
    出所の異なるファイルでも自動で文字コードを判定し、列の対応（馬番・馬名・オッズなど）を画面上で確認しながら取り込める。
    ※JRA-VAN・netkeibaへ直接アクセスして自動取得する機能ではない（JRA-VANは有料会員向けWindows専用SDK経由のみでの提供、
    netkeibaはブラウザからの自動取得がCORSで制限されるため技術的に不可）。手元でエクスポート・保存したファイルを読み込む方式。

## 構成

```
index.html      画面構造・タブ切り替え
css/style.css   スタイル
js/storage.js   localStorage汎用ヘルパー
js/tabelog.js   食べログ機能
js/keiba.js     競馬予想機能
js/app.js       タブ切り替え・初期化
```

新しい機能（旅行ルート、競馬予想など）を追加する際は、`js/`に新しいモジュールを追加し、
`index.html`に対応する`tab-panel`を追加する形で拡張できる。
