# 自分専用アプリ

個人利用のためのWebアプリ。データはブラウザのlocalStorageに保存され、サーバーは不要。

## 使い方

`index.html` をブラウザで開くだけで動作する。もしくは簡易サーバーで配信する場合:

```
python3 -m http.server 8000
```

## 機能

- **食べログ**: 訪問したお店を記録・検索・評価できる（実装済み）
- **旅行ルート作成**: 近日公開予定
- **競馬予想**: 近日公開予定（データ分析による予想支援を予定）

## 構成

```
index.html      画面構造・タブ切り替え
css/style.css   スタイル
js/storage.js   localStorage汎用ヘルパー
js/tabelog.js   食べログ機能
js/app.js       タブ切り替え・初期化
```

新しい機能（旅行ルート、競馬予想など）を追加する際は、`js/`に新しいモジュールを追加し、
`index.html`に対応する`tab-panel`を追加する形で拡張できる。
